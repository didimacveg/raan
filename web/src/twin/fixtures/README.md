# SGP4 verification vectors

`SGP4-VER.TLE` and `tcppver.out` are the reference test cases published with
Vallado, Crawford, Hujsak & Kelso, *Revisiting Spacetrack Report #3*, AIAA 2006-6753
(https://celestrak.org/publications/AIAA/2006-6753/). `tcppver.out` is the output of the
reference C++ implementation (WGS-72, AFSPC mode) for the 33 element sets in `SGP4-VER.TLE`.
The copies here are the ones distributed with the `sgp4` Python package (MIT licence).
